# R0.1 architecture scope

## Included

- canonical JSON and deterministic digests;
- tamper-evident event ledger;
- explicit policy decisions and consumable grants;
- evidence and certificate bindings;
- mission state machine;
- durable effect queue;
- research-attempt accounting before requests;
- verification CLI and repository gates.

## Explicitly excluded

- external LLM/runtime integration;
- Temporal, Neon or other production adapters;
- the live 800+ census;
- certified component adoption;
- UI, desktop, mobile, voice and creative studios;
- production deployment and release certification.

Adapters may be added later only behind STARCOM-owned interfaces and acceptance tests.
