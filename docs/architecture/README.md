# STARCOM authority model

STARCOM separates the following sovereign responsibilities:

- **Mission Kernel** — mission state, legal transitions, budgets and checkpoints.
- **Trust Plane** — identity, policy, grants, secrets, egress and approvals.
- **Proof Engine** — evidence bindings, independent verification and terminal certificates.
- **Durable Engine** — effects, idempotency, leases, retries and reconciliation.
- **Runtime Mesh** — replaceable agents, workers, models and adapters; never canonical authority.
- **Memory/Research fabrics** — governed derivations that remain reconstructible from canonical sources.

R0.1 implements only the minimal core needed to exercise these boundaries. It does not claim full STARCOM architecture coverage.
